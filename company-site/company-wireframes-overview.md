# Company Site — Static Page Wireframes

Low-fidelity wireframes for 5 static pages of a fictional small-business SaaS
site ("Brightline Co."), built for Session 9's Hands-On Activity, task 3.

## Pages

| # | Page | Key sections |
|---|---|---|
| 1 | `company-01-home.png` | Hero + CTA, 3 feature cards, stats band, testimonial |
| 2 | `company-02-about.png` | Company story, team photo, mission/vision, timeline |
| 3 | `company-03-team.png` | 6-person team grid (photo, name, role, social links) |
| 4 | `company-04-services.png` | 4 service listings with icons + descriptions, CTA banner |
| 5 | `company-05-contact.png` | Contact form, contact details, map placeholder |

`brightline-company-site-wireframes.pdf` combines all 5 pages in order — this
is the sign-off deliverable the activity asks for ("export to PDF for
sign-off").

## Consistent elements across all 5 pages

- Same top nav (logo, Home/About/Services/Team/Contact, "Get Started" button) —
  active page highlighted in the nav so it's clear which page you're on
- Same footer (company blurb, 3 link columns, copyright line)
- Same grayscale wireframe style as the other deliverables in this repo — no
  color/branding decisions made here on purpose, since that's a separate
  visual-design step
